# Hi there 👋

I build products and the tooling that ships them. 15+ years in TypeScript,
C#, and AWS, currently at Trimble where I'm moving from test architecture
into full-lifecycle feature work.

### 🛠️ Unified Engineering

I think the SDET/dev split causes more problems than it solves. One engineer
should own a feature from the API through the UI and the tests that keep it
honest. That's what I've been pushing for on my team, and it's mostly working.

### 🤖 AI tooling

I spend more time building the setup than prompting into it: custom Cursor
rules and skills, MCP integrations with Jira and Notion, agent workflows that
go from ticket to review-ready PR. The hard part isn't code generation. It's
the guardrails that keep output inside our conventions so a human reviewer
doesn't have to catch the same things every time.

### ⚡ Obsessed with DevEx

A test suite should be a tool, not a hurdle. Lately that's meant keeping a few
thousand Playwright specs fast and trustworthy enough that people actually run
them, and enough CI tuning to
[move fast without breaking things](https://xkcd.com/1428/).
